# Tejanjali Valavala — Official Website

Official website for Indian singer, songwriter, and musician **Tejanjali Valavala**, featuring music releases, visual archives, YouTube videos, Instagram reels, tour information, and verified contact channels.

## Tech Stack
- **Framework:** React + Vite
- **Language:** TypeScript
- **Styling:** Tailwind CSS + Radix UI / shadcn-ui
- **Animations:** Framer Motion
- **Icons:** Lucide React

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```

## Features
- **Hero Showcase:** Responsive, dynamic parallax hero with tailored image framing and Fit/Fill toggles.
- **Photos Gallery (`/photos`):** 13 authentic artist photos with category filters and full-screen lightbox.
- **Videos & Reels (`/videos`):** Playable YouTube video embeds and direct Instagram reels showcase.
- **Verified Contacts (`/info`):** Direct WhatsApp chat, official email, Instagram (@tejanjali_24), and YouTube (@tejanjalismckeyclub6077).
